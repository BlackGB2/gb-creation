GB CREATION WEBSITE — QUICK START

WHAT IS INCLUDED
- index.html       Home page
- projects.html    Separate projects page
- portfolio.html   Separate visual portfolio gallery
- about.html       About Gihan / GB Creation
- contact.html     Contact details and email form
- styles.css       Custom styling
- script.js        Navigation and contact form behaviour

HOW TO OPEN THE WEBSITE
1. Extract the ZIP file.
2. Open the extracted "gb-creation-website" folder.
3. Double-click index.html.
4. The website will open in your browser.

HOW TO OPEN IT USING COMMAND PROMPT
1. Open CMD inside the extracted folder.
2. Type: start index.html
3. Press Enter.

IMPORTANT NOTES
- This is a static multi-page starter website using Tailwind CSS through its browser Play CDN.
- An internet connection is needed for Tailwind, Google Fonts and remote Unsplash images.
- Tailwind's Play CDN is intended for development/prototyping. Before production deployment, install Tailwind with its CLI/build process.
- Unsplash images are temporary visual examples, not your actual design work. Replace them with your own exported graphics/mockups.
- The contact form opens the visitor's email application using a mailto link. It does not send messages through a server.
- Update the About page so the skills listed match your real experience.
- Check spelling, image rights, mobile layout and all links before publishing.
